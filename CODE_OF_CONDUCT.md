# Code of Conduct

This project is shared as a reference implementation for macOS security enthusiasts and AI agents. We expect interactions to be:

- **Respectful** — no harassment, trolling, or bad-faith behavior.
- **Constructive** — criticism is welcome when it is specific and actionable.
- **Security-aware** — do not submit reports containing live secrets, personal data, or undisclosed vulnerabilities in public channels.

Because this is a personal, owner-maintained repository, the maintainer reserves the right to remove any interaction that violates these principles.
