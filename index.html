Why this matters

macOS ya incluye buenas defensas (Gatekeeper, SIP, FileVault), pero no te avisa cuando algo cambia después de la instalación. Sentinel Arsenal añade visibilidad y respuesta automática.

1. Prevent

Gatekeeper, SIP, FileVault y el firewall de Apple bloquean la mayoría de amenazas antes de que ocurran.

2. Detect

LuLu, BlockBlock, OverSight y los agentes Sentinel detectan comportamiento sospechoso: conexiones, persistencia, micrófono, cambios de archivos.

3. Alert

Recibes notificaciones y logs con marcas de tiempo. Sabes qué pasó, cuándo y cómo investigarlo.

4. Respond

Algunos agentes actúan solos: matan procesos zombis, cierran servidores expuestos, rotan logs con firmas SHA-256.

¿Esto es un antivirus?

No. Sentinel Arsenal es una capa de visibilidad + automatización. No reemplaza Malwarebytes, un EDR comercial ni el sentido común. Pero te da alertas tempranas que la mayoría de usuarios nunca ven.

What you get

Haz clic en cualquier tarjeta para ver por qué existe, un ejemplo real y cómo instalarlo solo.

Filesystem Tripwire

SHA-256 baselines for critical files. Alerts when ~/.zshrc, SSH keys, or app settings change unexpectedly.

Why it matters

Si un malware o una app maliciosa modifica tus shells (.zshrc, .bashrc), tus claves SSH o la configuración de una app, Tripwire lo detecta en menos de 15 minutos.

Real example

Una app de terceros añade una línea a ~/.zshrc para ejecutarse en cada Terminal. Tripwire compara el hash actual con la línea base y dispara: "Changed: ~/.zshrc".

How to configure

Edita ~/.local/share/sentinel-arsenal/watchlist.txt y añade una ruta por línea. Usa ~ o $HOME. La primera ejecución crea la línea base; las siguientes comparan.

Install only this agent
./install.sh --agents=tripwire

MCP Zombie Killer

Kills orphaned node/mcp processes running >4h with >5% CPU. Essential if you run AI agents.

Why it matters

Los agentes de IA (Claude Code, Cursor, etc.) levantan procesos node o mcp. Si se desconectan mal, pueden quedar horas consumiendo CPU y batería. Este agente los mata con TERM primero, KILL si resisten.

Real example

A las 3 AM un agente MCP queda colgado al 30% CPU. A las 3:30, el agente envía SIGTERM. Si sigue vivo, SIGKILL. Recibes una notificación: "Terminated 1 long-running MCP/node processes".

Tune it

Variables de entorno: MAX_CPU (default 5.0%) y MAX_AGE_MIN (default 240 min). Edita el plist si quieres umbrales distintos.

Install only this agent
./install.sh --agents=mcp-zombie-killer
Every 30 min · RunAtLoad Read full doc →

BlockBlock Keepalive

Restarts Objective-See BlockBlock Helper.app if it stops running. Persistence protection should not go silent.

Why it matters

BlockBlock detecta cuando un programa intenta instalarse para arrancar automáticamente. Si su Helper.app se detiene, un malware puede persistir sin avisar. Este agente lo vuelve a levantar.

Real example

Tras una actualización de macOS, BlockBlock Helper no arranca. El agente detecta que no está en ejecución, lanza open "/Applications/BlockBlock Helper.app" y verifica que vuelva.

Prerequisite

Necesitas tener BlockBlock instalado. Sigue la guía: install-blockblock.md.

Install only this agent
./install.sh --agents=blockblock-keepalive
Every 30 min · RunAtLoad Read full doc →

LuLu Posture Monitor

Verifies LuLu is active and warns if rules are too permissive. No outbound traffic should be invisible.

Why it matters

LuLu es un cortafuegos de salida: pregunta antes de que cualquier app se conecte a internet. Si LuLu se detiene o tienes una regla any que permite todo, pierdes ese control. Este agente lo verifica cada día.

Real example

LuLu deja de ejecutarse tras un reinicio. El agente detecta que no hay proceso LuLu y envía una alerta. También avisa si detecta reglas any en la configuración.

Prerequisite

Instala LuLu primero: install-lulu.md. Sin LuLu, este agente solo escribe "LuLu.app not installed" en el log.

Install only this agent
./install.sh --agents=lulu-posture

Port Sweep Monitor

Detects processes binding to 0.0.0.0 or :: instead of localhost. Catches accidental LAN exposure.

Why it matters

Por defecto, muchos servidores de desarrollo (Vite, Next.js, Flask) escuchan en 0.0.0.0 para ser "fáciles". Eso expone tu Mac a la red local. En una cafetería, cualquiera puede conectarse.

Real example

Lanzas nvite --host sin darte cuenta y abre el puerto 5173 en 0.0.0.0. El agente detecta: "Wildcard listener: node 12345 *:5173".

Tune it

Añade puertos legítimos a ~/.local/share/sentinel-arsenal/port-allowlist.txt, uno por línea. Requiere lsof (brew install lsof).

Install only this agent
./install.sh --agents=port-sweep
Every 10 min · RunAtLoad Read full doc →

Canary Watch

Monitors decoy canary files. If an attacker reads or modifies sensitive dirs, the canary chirps first.

Why it matters

Un canario es un archivo señuelo. Si alguien entra a tu cuenta y toca archivos, el canario cambia o desaparece antes que tus datos reales. Es una alarma temprana barata y efectiva.

Real example

Colocas backup-config.txt en ~/Documents/sensitive/. Un script malicioso entra, lee todo el directorio y modifica el canario. Recibes: "Canary tampered: backup-config.txt".

How to configure

Edita ~/.local/share/sentinel-arsenal/canary-list.txt con formato nombre|contenido_esperado. El agente crea el archivo si no existe y verifica su hash.

Install only this agent
./install.sh --agents=canary-watch
At login, every event · RunAtLoad Read full doc →

Localhost-Only Guard

Detects dev servers exposed to the LAN. Optional kill mode for public Wi-Fi safety.

Why it matters

Port Sweep te avisa de escuchas wildcard. Localhost-Only Guard va más lejos: verifica que tus servidores de desarrollo usen 127.0.0.1 y, opcionalmente, los mata en Wi-Fi pública.

Real example

Trabajas desde un aeropuerto con next dev --hostname 0.0.0.0. El guard detecta el listener público y, si estás en SSID KILL_WILDCARD_ON_SSID="Airport_Free", envía SIGKILL y notifica.

Kill mode = opt-in

Por defecto solo alerta. Para activar la matanza automática, edita el plist y descomenta KILL_WILDCARD_ON_SSID= con el SSID exacto. Úsalo con cuidado.

Install only this agent
./install.sh --agents=localhost-guard
Every 30 s · RunAtLoad Read full doc →

macOS Audit

Periodic posture report: FileVault, SIP, Gatekeeper, users, SSH, permissions, and third-party system extensions.

Why it matters

Las configuraciones "por seguridad" se desactivan con el tiempo: FileVault off tras una reinstalación, SIP alert-only en modo recovery, Gatekeeper desactivado con sudo spctl --master-disable. Este agente revisa el estado cada 6 horas.

What it checks

  • FileVault enabled
  • SIP enabled & not "Configuration Disabled"
  • Gatekeeper status
  • SSH root login disabled
  • Users con UID 0 / administradores
  • System extensions de terceros instaladas

Permission level

Algunas comprobaciones requieren privilegios elevados. Para el reporte completo, añade el agente a /etc/sudoers.d/ (ver doc). Sin sudo, simplemente informa de campos vacíos.

Install only this agent
./install.sh --agents=macos-audit
Daily 03:00 + every 6 h · RunAtLoad Read full doc →

YARA Monthly

Scans a configurable folder with YARA rules. Defaults to ~/Downloads. Aborts if the rule fails to compile.

Why it matters

YARA es el estándar de la industria para detectar familias de malware por patrones. Incluimos reglas básicas para macros ofuscadas, scripts sospechosos y binarios rares. La regla por defecto es un punto de partida, no un antivirus.

Real example

Descargas un .zip con un .dmg adjunto. YARA escanea ~/Downloads el primer día de mes y reporta: "suspect_macro_doc rule matched: Contrato_Falso.docm".

Prerequisite

Necesitas yara instalado: brew install yara. Puedes sustituir nuestra regla básica por el repositorio de reglas que prefieras editando la ruta en el plist.

Install only this agent
./install.sh --agents=yara-monthly
1st of month 03:00 · RunAtLoad Read full doc →

Audit Log Rotate

Rotates audit logs with SHA-256 manifests. Keeps evidence tamper-evident and bounded in size.

Why it matters

Si un atacante entra, lo primero que hace es borrar logs. Con rotación + manifest SHA-256, tienes copias antiguas firmadas en disco. Detectar la manipulación es más fácil porque puedes comparar hashes.

What it does

Cada lunes comprime logs mayores de 5 MB en ~/.local/share/sentinel-arsenal/logs/, genera un manifest.sha256 y limpia archivos con más de 30 días.

Forensic note

El manifest se guarda en el propio directorio de logs, por lo que un atacante con acceso root podría regenerarlo. Para máxima integridad, copia el manifest a un medio externo o usa la cadena de auditoría separada del agente Chain Writer (en desarrollo).

Install only this agent
./install.sh --agents=auditlog-rotate
Mondays 09:00 · RunAtLoad Read full doc →

Login Item Inspector

Audits LaunchAgents and login items hourly. Surfaces new persistence you did not authorize.

Why it matters

El 80% del malware en macOS gana si consigue persistencia: un LaunchAgent, un LaunchDaemon, un login item o un perfil de configuración. Este agente toma un inventario y avisa cuando aparece algo nuevo.

Real example

Instalas una app "gratuita" que deja un LaunchAgent en ~/Library/LaunchAgents/com.ejemplo.miner.plist. Una hora después recibes: "New login item: com.ejemplo.miner".

False positives

Cada vez que instales una app legítima con LaunchAgent (Dropbox, Docker, 1Password) recibirás una alerta. Esto es correcto: tú decides si es legítimo. Añade el label a tu lista de autorizados si lo reconoces.

Install only this agent
./install.sh --agents=login-item-inspector
Hourly · RunAtLoad Read full doc →

How to read an alert

Every Sentinel alert follows the same pattern so you can decide in seconds.

1

What changed?

La primera línea dice el evento: "Changed: ~/.zshrc", "New login item: ..." o "Wildcard listener ...". Lee eso primero.

2

When and where?

Los logs incluyen timestamp ISO, agente que disparó, y ruta al plist. Busca el archivo en ~/.local/share/sentinel-arsenal/logs/.

3

Is it expected?

Si tú acabas de instalar una app o modificar un archivo, es ruido. Si no sabes qué lo causó, abre el log y sigue la guía del agente. No ignores alertas desconocidas.

Example log entry — ~/.local/share/sentinel-arsenal/logs/tripwire.log 
[2026-07-17T09:14:22+02:00] [tripwire] ALERT Changed: /Users/roberto/.zshrc
  old: a3f7c2... | new: 8e1d4b...
  See docs/tripwire.md#investigating

Questions answered

Lo que suele preguntarse antes de instalar algo que toca launchd.

Will this slow down my Mac?

No. Los agentes usan launchd, el planificador nativo de macOS. La mayoría corre una vez al día o cada 15-30 minutos, y solo hacen ps, awk o shasum sobre pocos archivos. En una MacBook Air M1 el conjunto completo consume menos CPU que un solo frame de Safari.

Do I need admin rights?

Para la mayoría, no. Los LaunchAgents se instalan en ~/Library/LaunchAgents/ y corren como tu usuario. Solo macOS Audit necesita sudo para leer SIP/FileVault y es opcional.

Is this an antivirus?

No. Es una capa de visibilidad y automatización. Complementa, no sustituye, a Malwarebytes, un EDR o el sentido común. Si YARA encuentra algo, usa Malwarebytes para limpiarlo.

Can I uninstall one agent?

Sí. Usa el instalador: ./install.sh --uninstall --agents=tripwire. También puedes desactivar manualmente con launchctl unload ~/Library/LaunchAgents/com.sentinel.tripwire.plist.

What if an alert is a false positive?

Eso es correcto y esperado: una alerta significa "algo cambió". Si el cambio fue legítimo, actualiza la línea base de Tripwire, añade el puerto a la allowlist, o añade el LaunchAgent a tu lista de autorizados. La documentación de cada agente explica cómo.

Why not just use a commercial EDR?

Puedes (y deberías) usar ambos. Un EDR comercial ve amenazas conocidas. Sentinel Arsenal ve tu configuración: cambios en tus shells, servidores expuestos, procesos zombis de IA, persistencia nueva. Es tuyo, transparente y gratuito.
