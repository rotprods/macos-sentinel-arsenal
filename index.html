What you get

A layered defense that runs quietly in the background. Each agent does one thing well.

Filesystem Tripwire

SHA-256 baselines for critical files. Alerts when ~/.zshrc, SSH keys, or app settings change unexpectedly.

Every 15 min Integrity

MCP Zombie Killer

Kills orphaned node/mcp processes running >4h with >5% CPU. Essential if you run AI agents.

Every 30 min Process Hygiene

BlockBlock Keepalive

Restarts Objective-See BlockBlock Helper.app if it stops running. Persistence protection should not go silent.

Every 30 min Anti-Persistence

LuLu Posture Monitor

Verifies LuLu is active and warns if allowInstalled is too permissive. No outbound traffic should be invisible.

10:00 + login Firewall

Port Sweep Monitor

Detects processes binding to 0.0.0.0 or :: instead of localhost. Catches accidental LAN exposure.

Every 10 min Network

Canary Watch

Monitors decoy canary files. If an attacker reads or modifies sensitive dirs, the canary chirps first.

At login, continuous Honeypot

Localhost-Only Guard

Detects dev servers exposed to the LAN. Optional kill mode for public Wi-Fi safety.

Every 30 s Exposure Control

macOS Audit

Periodic posture report: FileVault, SIP, Gatekeeper, users, SSH, permissions, and third-party system extensions.

Daily 03:00 + 6h Posture

YARA Monthly

Scans a configurable folder with YARA rules. Defaults to ~/Downloads. Aborts if the rule fails to compile.

1st of month 03:00 Malware Scan

Audit Log Rotate

Rotates audit logs with SHA-256 manifests. Keeps evidence tamper-evident and bounded in size.

Mondays 09:00 Forensics

Login Item Inspector

Audits LaunchAgents and login items hourly. Surfaces new persistence you did not authorize.

Hourly Persistence Audit

Install guide

Install in 4 steps

No root required for most agents. Review the script before running it.

1

Install the external tools first

LuLu, BlockBlock, Malwarebytes, and OverSight form the foundation. See the guides below.

LuLu BlockBlock Malwarebytes OverSight
2

Clone the repo

Get the latest code directly from GitHub.

terminal 
git clone https://github.com/rotprods/macos-sentinel-arsenal.git
cd macos-sentinel-arsenal
3

Run the installer

Choose interactive or silent install. Add --dry-run to preview changes.

terminal 
./install.sh --all --non-interactive
4

Verify

Confirm the agents are loaded and logs are being written.

terminal 
launchctl list | grep com.sentinel
ls ~/.local/share/sentinel-arsenal/logs/
